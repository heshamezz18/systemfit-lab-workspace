# SystemFit Lab Workspace

[Open the live demo](https://heshamezz18.github.io/systemfit-lab-workspace/)

A customizable Arabic and English laboratory demonstration. Set the lab name and logo in Lab settings. The registry connects specimen workflows, pathology and molecular results, referrals, payments, tasks and case conversations. All edits and uploaded demo files are stored in the current browser. Use fictional records only. Multi-user access and permissions require a dedicated server.

Open index.html directly or serve the repository root with a static server.
